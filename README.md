# 데일리 이슈

5분이면 읽는 시사 이슈 데일리 트래킹 웹 리포트. 종이신문 스타일, 사진은 흑백 망점 처리, 사진·제목을 누르면 원문 기사로 이동합니다.

- **열기**: `index.html` 더블클릭 (인터넷 연결 필요 — 폰트와 기사 사진을 불러옵니다). 지난 호는 주소 뒤에 `#2026-10-02` 또는 ← → 키.
- **자동 갱신**: 매일 오전 10시, Claude 예약 작업이 `EDITOR_GUIDE.md` 대로 새 호(`data/날짜.js`)를 만들고 검증합니다. Claude 앱이 켜져 있어야 실행됩니다(꺼져 있으면 다음 실행 때 이어서 실행).
- **수동 갱신**: Claude에게 “오늘 호 만들어줘 (EDITOR_GUIDE.md 대로)”라고 요청.
- **구조**: `index.html` · `assets/`(디자인·렌더러) · `data/`(호별 내용) · `tools/`(수집·검증 스크립트) · `work/`(작업용 임시 파일, 지워도 됨)
- **고치는 곳**: 제호·문구 `assets/app.js` 맨 위 `SITE` · 색·글꼴 `assets/style.css` 맨 위 `:root` · 매체 목록 `tools/sources.json`
- 요약은 AI가 작성하므로 오류가 있을 수 있습니다. 중요한 내용은 원문 기사로 확인하세요. 사진의 저작권은 각 매체에 있습니다.
